# KOCHIMI — Portfolio

Portfolio professionnel d’Abari Kouley KOCHIMI LALA : ingénierie des systèmes d’information, développement applicatif, data et infrastructure IT.

[Consulter le portfolio](https://kochimi-portfolio.netlify.app/) · [Profil GitHub](https://github.com/kolex-lab95)

Site statique en HTML, CSS et JavaScript, bilingue français/anglais et adapté aux écrans mobiles. Il présente mes projets, mon parcours et mon CV téléchargeable.

## Utilisation

Ouvrir `index.html` dans un navigateur. Pour un hébergement statique, publier le dossier à la racine du site ; aucune compilation n’est nécessaire.
